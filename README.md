# Project Insanity Learning

A learning and experimentation project based on the original Project Insanity 317 server and client.

## About This Repository

This repository is being used to learn Java and RSPS development by studying, fixing and gradually improving an older Project Insanity codebase.

The initial files were obtained from a 2013 Rune-Server re-upload described as the bare original Project Insanity release uploaded by Sanity.

## Original Source and Credits

Project Insanity was originally released by **Sanity**, with contributions from its respective developers and the wider RSPS community.

- [Project Insanity 317 – Server & Client re-upload](https://rune-server.org/threads/re-upload-project-insanity-317-server-client-re-upload.494689/)

I do not claim ownership of the original Project Insanity source or included RuneScape assets.

## Requirements

- IntelliJ IDEA
- Java 8 JDK (Amazon Corretto 1.8 recommended)

## IntelliJ Setup

This project is run through IntelliJ IDEA with the following configuration:

- **Project SDK:** Amazon Corretto 1.8
- **Language level:** Java 8

To configure these settings:

1. Open **File → Project Structure → Project**.
2. Set **SDK** to **Amazon Corretto 1.8**.
3. Set **Language level** to **8 – Lambdas, type annotations, etc.**
4. Apply the changes and allow IntelliJ to index the project.
